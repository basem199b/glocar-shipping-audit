# GLO CAR Shipping Audit

نظام تدقيق ومطابقة فواتير شركات الشحن لمتجر GLO CAR.

## الهدف
تحليل ربح وخسارة الشحن فقط، بدون الدخول في قيمة الطلبات أو تكلفة المنتجات.

## النسخة الأولى MVP
- رفع ملف Excel صادر من سلة يحتوي على الشحنات.
- رفع ملف PDF لفاتورة شركة الشحن.
- استخراج أرقام البوالص والتكاليف من الفاتورة.
- مطابقة البوالص بين سلة وفاتورة شركة الشحن.
- كشف البوالص المكررة من فواتير سابقة.
- كشف البوالص الموجودة بالفاتورة وغير التابعة للمتجر.
- كشف البوالص الموجودة بسلة وغير الموجودة بالفاتورة.
- حساب ربح أو خسارة الشحن لكل بوليصة.
- اعتماد وإقفال فاتورة شركة الشحن.
- منع اعتماد البوليصة مرة ثانية إلا بمراجعة مدير.
